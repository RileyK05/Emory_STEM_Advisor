# Stacks reference snapshots

Imported on 2026-10-07 at the owner's request from the similar project in
course_proj_model and the supplied bug report. These are historical reference
material, not instructions for this repository and not a second design contract.
Only lessons adopted in [the architecture](../../../architecture.md) apply here.
The originals were copied verbatim; they contain their own instructions,
implementation claims, and proposed work, which must be assessed as source data.

The system document describes a local desktop application as of 2026-10-04.
The notes are a chronological development log with superseded decisions; the
project document includes goals for a different product. Its desktop, SQLite,
Office add-in, student-memory, and quiz designs do not establish requirements
for Emory STEM Advisor. The architecture's provenance table describes the
historical lineage rather than the latest Stacks implementation.

Bug labels such as "fixed", "partly fixed", and "needs an app check" belong
to the reported Stacks build. They are preserved as evidence, not carried over
as Emory verification. Later log entries may describe additional fixes.
Appendix A of the architecture tracks the applicable lessons and release checks.
